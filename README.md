# Mobile Invoice OCR

**An Android app for invoice scanning, data extraction, and delivery management.**

![Version](https://img.shields.io/badge/version-1.0.0-blue)
![Status](https://img.shields.io/badge/status-archived-red)
![Platform](https://img.shields.io/badge/platform-Android-brightgreen)
![License](https://img.shields.io/badge/license-MIT-orange)

## Features

- Photo capture with CameraX for invoice scanning
- On-device OCR via Google ML Kit text recognition
- Room database for persistent storage
- Digital signature capture
- Proof of delivery (POD) photos
- Route optimization with interactive map
- Drag-and-drop reordering of delivery stops
- Export to CSV, Excel/TSV, JSON, Markdown

## Tech Stack

Java 8, Android API 26-34, Google ML Kit, Room (SQLite), Gradle 8.5, CameraX, Material Design 3
